# Terminal2 source audit and migration map

## Source identity

- Repository: <https://github.com/michael-heyns/Terminal2>
- Pinned commit: `d3adbd301963b729885cc41fb75b3a80bcdf5472`
- Upstream tag: `v1.6.1.4`
- Upstream description: Terminal2 v1.6.1.4 (December 2025)
- License: GNU GPL-3.0-or-later; preserve copyright, license, and notices.
- Original project: WinForms, .NET Framework 4.8, Windows-only; no upstream automated tests were found in the pinned checkout.

The pinned source checkout is retained locally under `external/Terminal2` for audit and reference; that folder is intentionally excluded from release commits. SIGNALFORGE is not built from the legacy checkout. The public migration record identifies the upstream repository and commit, and the root GPL-3.0-or-later license retains the applicable license text. The new implementation uses portable domain services and explicit compatibility tests instead of carrying the WinForms UI forward.

## Behavior and defect decisions

The migration keeps valid Terminal2 workflows and wire semantics while making defects explicit. `StxEtx.IsHex` returns true even for invalid input, treats invalid nibbles as zero, and some `$` probes index beyond the string. `FrmMain.IsHex` also returns true unconditionally, while `GetHex` maps invalid nibbles to zero; malformed `$..` command text can therefore transmit an unintended byte. SIGNALFORGE rejects malformed escapes with a visible diagnostic instead of preserving that corruption. These malformed-input behaviors are not compatibility requirements: malformed frames and send escapes produce typed errors, while valid reference vectors must match original bytes exactly. `Comms`'s TCP `Write` return value and blocking listener behavior are likewise corrected while preserving successful transmission and server-mode intent.

TCP is a byte stream. A read callback boundary is not a packet boundary. Protocol decoders therefore receive ordered fragments and preserve incomplete suffixes; the trace stores the original chunk boundaries and bytes separately from reconstructed frames.

The original display has additional migration behavior: the receive surface retains up to 10,000 lines, command output history up to 1,000 entries, supports click-to-recall, CR/LF rendering markers, timestamps, freeze/unfreeze, backward search, and stop-on-substring. SIGNALFORGE provides a bounded 5,000-line history with complete-line search and stop-at, freeze/resume that leaves trace capture running, explicit CR/LF ending labels, line timestamps, and a live partial-line preview. Selecting a completed row recalls its display text without sending; the smaller history cap remains a difference. The four macro banks are keyed by 0–191. F1–F12 plus Shift/Ctrl/Alt now select the corresponding slot in a user-selected bank, correcting Terminal2's keyboard handler, which ignores its active bank offset. Text-file transfer now has a dedicated compatibility workflow; XMODEM is not provided by the general terminal or simulator transport.

Further UI audit findings: event queue overflow above 3,000 queued strings clears the queue, unfreezes display, and disconnects. Input/output histories have different limits. The macro grid exposes four banks but old F-key hotkeys index bank zero only. The embedded help and current key behavior diverge on Escape and Up/Down. `Log` (used by the UI) is a background-thread, static queued logger; `Logging` is a separate synchronous class with no found call site. XMODEM transfers 128-byte CRC blocks and is serial-only. The Inspect surface offers RTF/text import/export, Base64 conversion, search/replace, and selected character/decimal/hex display. These distinctions are tracked as individual parity items rather than assumed from a generic terminal or trace view.

## Measured engineering challenges

The hardest compatibility boundary is that Terminal2 expresses outbound bytes using a string notation (`$HH`, `$$`) while TCP and serial carry arbitrary byte streams. The migrated parser and STX/ETX codec are compared with source-derived copies of the pinned `FrmMain.SendDollarString` and `STXETX.Encode/Verify/Decode` algorithms. The first-match filter matcher is also checked differentially against `Filters.FindApplicableFilter`, including the legacy current-culture lowercasing behavior. These references cover valid legacy behavior; malformed-escape handling is deliberately stricter and is not byte-for-byte defect emulation.

The second measured constraint is test-thread ownership: the original 261-test suite passed on Windows and Ubuntu 26.04 under WSL2 in the CI-equivalent split of 260 tests plus the dispatcher workflow in isolation. The current 266-test suite passes locally on Windows and in the hosted native Windows/Linux/macOS matrix using the same split. The combined Windows invocation exceeds the 3-minute hang limit; the combined Linux invocation fails when Avalonia's process-wide dispatcher is owned by another test thread. CI uses the validated split on all runners; combined-run isolation remains a known test-harness limitation.

Codec throughput was measured separately from UI and transport work. The verification record reports five-sample medians of 3,166,461 Modbus TCP decodes/s (315.8 ns, 552 B/op) and 32,110,563 Modbus RTU CRC calculations/s (31.1 ns, 0 B/op) on Windows x64; the corresponding Ubuntu 26.04 WSL2 medians were 2,876,711 decodes/s (347.6 ns, 552 B/op) and 36,917,806 CRC calculations/s (27.1 ns, 0 B/op). These are isolated in-process codec measurements from the recorded SDK/runtime and are not whole-application, socket, hardware, or cross-platform performance claims. The verification record also captures the exact build, test, startup, and platform scope.

## Compatibility checks

The compatibility suite should prove:

1. Valid Terminal2 `$HH` command text maps to the same output bytes.
2. STX/ETX/DLE escaping and XOR LRC match original source vectors.
3. Legacy profile values, all 192 macro slots, all 48 titles, all 12 filters, colors, and connection options import and export without semantic loss.
4. First-match filter slot ordering, match modes, offsets and current-culture case folding match the pinned `Filters.FindApplicableFilter` algorithm.
5. Text macro directives preserve ordering, CR/LF, delay, repetition, note, and framing behavior.
6. TCP fragmentation does not change protocol output or the recorded byte stream.
