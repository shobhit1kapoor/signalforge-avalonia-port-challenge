# Terminal2 profile fixture

`Default.profile` was generated by running the pinned Terminal2 v1.6.1.4 source at commit `d3adbd301963b729885cc41fb75b3a80bcdf5472` and exporting its default profile. It contains no custom user profile data. The generated export timestamp and temporary local log-directory path were sanitized; all remaining profile fields are from the original application's default export.
